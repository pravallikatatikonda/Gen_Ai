# AI Resume Screening System with LangChain

## Objective
This project is an AI-powered Resume Screening System built using LangChain and HuggingFace.

## Features
- Resume skill extraction
- Resume-job matching
- Candidate scoring
- Explainable AI output
- Modular pipeline design

## Technologies Used
- Python
- LangChain
- HuggingFace Transformers
- LangSmith

## Pipeline
Resume → Extract → Match → Score → Explain

## Run Project

```bash
pip install -r requirements.txt
py main.py
```
